# HTTP Download Speed Test

Консольная утилита на Python для измерения скорости скачивания данных по HTTP.

## Возможности

- Выполнение 10 последовательных HTTP-запросов к указанному URL.
- Измерение времени выполнения каждого запроса.
- Расчёт среднего времени запроса.
- Подсчёт общего объёма полученных данных.
- Расчёт средней скорости скачивания.

## Технологии

- Python 3.10+
- [HTTPX](https://www.python-httpx.org/) — асинхронный HTTP-клиент.
- asyncio — управление асинхронным выполнением.

## Установка

Клонировать репозиторий:

```bash
git clone <repository-url>
cd <repository-folder>
```

Установить зависимость:

```bash
pip install httpx
```

## Запуск

```bash
python script.py
```

После запуска необходимо ввести URL ресурса, на котором будут производится замеры.


## Единицы измерения

- Время выполнения запросов: секунды (сек.).
- Объём данных: мегабайты (MB).
- Скорость скачивания: мегабайты в секунду (MB/s).

Скорость рассчитывается как отношение общего объёма полученных данных к суммарному времени выполнения всех запросов.
